# I-29 Speedway v1.0.1

Maintenance release on top of v1.0.0. Install exactly as before (unzip into the Assetto Corsa root or drag onto Content Manager; it replaces `content/tracks/vf_i29_speedway/`).

## Changes
- **Replay cameras rebuilt:** 3 camera sets per layout (Long and Short Course), with corner-apex and straight cameras, line-of-sight validated.
- **Dirt/gravel restored:** dirt and gravel textures, ruts and surfaces are back.
- Version bumped to 1.0.1 in both layouts.

See `docs/RELEASE_NOTES_v1.0.0.md` in the repository for the full v1.0.0 feature list and known limitations.
