## 1. `zw_rpm/{main,short}/data/surfaces.ini`
Physics meshes found in the kn5s: `1ROAD_001..010`, `1ROAD_pitout`, `1PITS`, `1PITS_IN`, `1PITS_OUT`, `1WALL_*` (zw_rpm_physical.kn5); `1CURBS_NEW`, `1GRASS`, `1CONCRETE_001`, `1DRAGstrip` (zw_rpm.kn5). AC maps a mesh to a surface by matching `KEY` against the name after the leading digit (prefix match), so `KEY=CURB` covers `1CURBS_NEW`.
- CURB: `IS_VALID_TRACK` 0 → 1 (curbs are part of the track; cars using curbs were being flagged).
- GRASS: `BLACK_FLAG_TIME` 0 → 5. With 0, invalid surfaces don't register cuts in race sessions (see Emperor Servers / assetto-server-manager wiki, "Fixing Track Cut Detection in Race Sessions": https://wiki.emperorservers.com/assetto-corsa-server-manager/fixing-track-cut-detection-in-race-sessions).
- Added `SURFACE_4 KEY=CONCRETE` and `SURFACE_5 KEY=DRAG` (invalid, BLACK_FLAG_TIME=5). These meshes had no KEY before. **Test:** confirm in-game that these are run-off/drag-strip only and not part of a legit racing line; flip to valid if needed.
- CRLF line endings preserved.
