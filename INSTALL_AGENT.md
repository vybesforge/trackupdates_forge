# I-29 Speedway (zw_rpm) — install instructions for an automation agent

Goal: install this Assetto Corsa track from GitHub so the user only has to launch it.

## Source
- Repo: https://github.com/vybesforge/trackupdates_forge
- Branch: `i29-speedway`
- Track folder in repo: `zw_rpm/`
- Large files (`.kn5`, `.dds`, `.fbx`, `.png`, `.jpg`, `.ai`) are stored with **Git LFS**. A plain "Download ZIP" from GitHub gives LFS pointer files, NOT the real data. Use git + git-lfs.

## Prerequisites (Windows VR/gaming PC)
1. Git for Windows (includes git-lfs): `winget install --id Git.Git -e`
2. `git lfs install`
3. Assetto Corsa installed (Steam). Default path:
   `C:\Program Files (x86)\Steam\steamapps\common\assettocorsa`
   If not there, read Steam library folders from
   `C:\Program Files (x86)\Steam\steamapps\libraryfolders.vdf` and look for `steamapps\common\assettocorsa`.
4. Recommended: Content Manager + Custom Shaders Patch (CSP) 0.2.x or newer (grass FX, ext_config).
   **Required for the animated drag-strip Christmas tree:** CSP 0.1.79 or newer with track Lua scripts enabled
   (`extension/ext_config.ini` → `[SCRIPT_DRAG_TREE]` → `extension/drag_tree.lua`). Without CSP the track still loads; the pole bulbs stay dark, but the vanilla app `apps/python/i29_dragtree` shows the same reactive two-lane tree and timeslip on the monitor (VR9).
   **Layouts / AI (VR7):** `main` = I-29 Speedway Long Course (full circuit; the short-course hairpin is coned off and counts as off-track via `zw_vr7_longcut.kn5`), `short` = I-29 Speedway Short Course. AI lines were regenerated by `tools/vr7_ai.py` and checked by `tools/vr7_ai_validate.py`. The zwiss originals are in `assets_src/ai_zwiss_orig/`. If AI behaves badly, record a new line in game.
   **Night lighting (VR6):** the pit, paddock and drag-strip lights are CSP `[LIGHT_VR6_*]` entries in `extension/ext_config.ini`. There are 22 spot lights with `CONDITION = NIGHT_SMOOTH` and `FADE_AT = 700`, generated by `tools/vr6_props.py`. They only show with CSP and lights enabled. Without CSP the lamp heads are just unlit grey.

## Install (PowerShell)
```powershell
$AC = "C:\Program Files (x86)\Steam\steamapps\common\assettocorsa"   # adjust if needed
$Work = "$env:USERPROFILE\trackupdates_forge"
git lfs install
if (Test-Path $Work) { git -C $Work fetch origin; git -C $Work checkout i29-speedway; git -C $Work pull; git -C $Work lfs pull }
else { git clone --branch i29-speedway https://github.com/vybesforge/trackupdates_forge.git $Work; git -C $Work lfs pull }

# Verify LFS actually downloaded (main kn5 must be ~240 MB, not ~130 bytes)
$kn5 = Get-Item "$Work\zw_rpm\zw_rpm.kn5"
if ($kn5.Length -lt 10MB) { throw "LFS files not downloaded; run git lfs pull" }

# Back up any existing install, then copy
$Dest = "$AC\content\tracks\zw_rpm"
if (Test-Path $Dest) { Rename-Item $Dest "zw_rpm.bak_$(Get-Date -Format yyyyMMdd_HHmmss)" }
Copy-Item "$Work\zw_rpm" $Dest -Recurse
# VR9: vanilla-AC drag tree app (optional, no CSP needed)
$App = "$AC\apps\python\i29_dragtree"
if (Test-Path $App) { Remove-Item $App -Recurse -Force }
Copy-Item "$Work\apps\python\i29_dragtree" $App -Recurse
```
Alternative: unzip the release zip (`I-29_Speedway_v1.0.0-rc1.zip`, built by `tools/build_release.py`) into `$AC`; it contains `content\tracks\zw_rpm` and `apps\python\i29_dragtree`.

## Verify
- `$Dest\models_main.ini` and `models_short.ini` exist, and `zw_rpm_own.kn5` `zw_ext.kn5` (~40 MB, north extension), `zw_dragexit.kn5`, and `zw_tents.kn5` are present.
- `$Dest\ui\main\ui_track.json` and `$Dest\ui\short\ui_track.json` exist.
- In Content Manager → Drive → Track, the track shows two layouts: "I-29 Speedway Long Course" (main, 3.644 km) and "I-29 Speedway Short Course" (short, 2.380 km); folder id stays `zw_rpm`.
- `$AC\apps\python\i29_dragtree\i29_dragtree.py` exists; enable "I-29 Drag Tree" in CM → Settings → Assetto Corsa → Apps (or the in-game app bar). If it doesn't appear, restart Content Manager.

## Update later
Re-run the Install block; it pulls the latest branch and replaces the track (old copy kept as `zw_rpm.bak_*`).

## Uninstall / roll back
Delete `$AC\content\tracks\zw_rpm` and rename the newest `zw_rpm.bak_*` back to `zw_rpm` if desired.

## Hand-off to the user (what to test)
1. Load each layout once in practice (VR).
2. Curbs should NOT trigger cuts; four wheels on grass SHOULD (server race).
3. Short layout: sector 1/2 and lap timing work.
4. VR2 surfaces: tent paddock feels gravel (slow, dusty, no flag); access roads outside the track look like jointed concrete; grass runs to the track edge at corners (no brick/cobble look).
5. Visual check: larger timing tower (~15x10 m), brake boards 3/2/1, marshal hut, grandstands with closed risers, flagpole, Poly Haven tree billboards, armco/tire/tent specular, ground blending, water, props.
6. Short-course main straight vs. real drag strip position.
7. North extension (both layouts): drive off-course north via 190th St / 188th St to the two fuel stations; no flags or cuts on these roads (XROAD/XLOT); four-way stop at US-34 (4 stop signs, readable); canopy signs readable from both sides; lots smooth-edged; invisible walls stop you at the I-29 interchange (east), north and west edges; ground colour seam at the old track boundary; VR frame rate.
8. Short-course bumps: T1 (turning off the drag strip) has a small seam lip + gentle hump; T5 (back onto the drag strip) a lip + slight hump. Should be felt in FFB/suspension, not unsettle the car; main layout straight unaffected at T1; AI still drives normally.
9. Drag strip (1/8 mile, west strip): exits A (~mid-shutdown), B (later) and C (strip end) turn LEFT through armco gaps onto crossovers and the return road back south to staging/pits; E is a short stub RIGHT to the circuit just past the east armco end. All drivable, no flags, light-grey asphalt matching the ground photo, edges blend, no wall contact in gaps, armco intact elsewhere; racing on the main straight unaffected near E.
10. Paddock: original VF tent nearest the pit lane stays; two VF-style big tents replace the old pit tents (drivenbycrusemob.com + neutral); three smaller ad tents behind them (vybesforge.com / drivenbycrusemob.com / vybesforge.com). Spelling is Cruse (not Cruise). Check text legibility and the drive lane between rows.
11. VR3: north roads/highway and station lots smooth, full grip (no ice), can climb into the station, no reset/out-of-bounds on lots; track→highway road not dusty; drag exits keep grass between exit and strip, no fence at exit A; no wrecker at the track exit; no roadside fence across from the highway exit; tree backdrop now behind the stations; short T1/T5 transitions look like the drag-exit asphalt and still have their bumps. Confirm `zw_tents.kn5` is present after install.
12. VR9 lidar: the track now follows real ground heights (±0.4 m on the road). Look for steps or floating/buried kerbs, cars rolling in the pit boxes (paddock now sloped), and the VR frame rate (denser meshes).
13. VR9 drag tree (CSP): roll into a lane. Your lane's pre-stage and stage bulbs should light; hold 1 s, ambers, then green. Jumping early gives that lane's red. A timeslip message appears after 1/8 mile. With nobody near for 10 s the demo loop runs.
14. VR9 drag tree app (vanilla AC, monitor): same tree and timeslip in the window. Check whether it is visible in the headset (expected: not without CSP), and try a run with a second (online) car in the other lane.
15. VR9c hotfix: drive off-road onto grass everywhere (both layouts), the pit exit / exit road to the public road, the north-extension road where it passes the railway embankment (step off the road sideways), and into a pond. You must never fall through the world.
16. VR10 north extension: drive 190th/188th St, the station lots and the US-34 stop. The ground is now real lidar height (up to ~7 m higher than before). Look for steps at the old track boundary and the access-road join, buried or floating signs, poles, canopies and trees, and invisible walls in the wrong place. You must never fall through.
17. VR10 drag start line: pull up to the painted white line. The stage bulb should light when your front tyres reach the line, and pre-stage just before it (at the short ticks).
18. VR10 figures: walk or drive up to the two people at the shed. Check the faces, hair and cap up close and the contact shadows. Check that the frame rate is unchanged.
Report any issue back to the user's Grok Bot.
